Arquitetura de Atualização

Como este painel se mantém sempre atual
1. Planilhas do clienteExcel de Frota, Preventivas, Corretivas, Acidentes, Descontos, KM (e Multas/Abastecimento quando disponíveis)
2. Importação (aba Importar)O Admin sobe os arquivos aqui mesmo — leitura acontece no navegador, sem servidor
3. Processamento automáticoKPIs, gráficos e alertas recalculados na hora
4. Painel atualizadoTodas as páginas refletem os novos dados imediatamente

Importar Planilhas

Envie os arquivos do mês. O painel inteiro é recalculado automaticamente — sem precisar de mim, sem precisar do Power BI. Mantenha os nomes de coluna iguais aos das planilhas originais.

Importar Base Consolidada (Novo)

Envie apenas o arquivo BASE_CONSOLIDADA.xlsx gerado pelo Power Query. O sistema valida, mostra um preview e só grava no banco depois da sua confirmação.
